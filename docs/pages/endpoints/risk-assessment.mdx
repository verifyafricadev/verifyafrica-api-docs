# Risk Assessment

Assess the fraud and identity risk score for a given individual based on their phone number and a configured risk check.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/risk_assessment/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
risk_assessment
```

## Use Cases

- Fraud scoring during account opening
- Transaction risk evaluation
- Identity-based risk tiering

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `email` | string | Yes | Customer's email address. |
| `language` | string | Yes | Language code (e.g. `"EN"`, `"FR"`). |
| `risk_assessment` | object | Yes | Risk assessment configuration. See nested fields below. |

### `risk_assessment` object

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `phone_number` | string | Yes | Phone number to assess, including country dialing code (e.g. `"+2348012345678"`). |
| `risk_reference` | string | Yes | Configured risk-assessment check ID. See allowed values below. |

### Allowed `risk_reference` values

| Value | Check |
| --- | --- |
| `3miTFA` | Gaming/Gambling |
| `iSSH1t` | Crypto/NFT/DeFi |
| `m8bcQM` | Banking/Finance/FinTech/Investments |
| `oDPp6l` | Trading Risk |
| `G1uc7d` | Trading Risk Assessment |
| `cY0m7x` | Risk Management |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.

**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/risk_assessment/`

Authenticate with `Authorization: Bearer <VA-…api-key>`. The product path selects the verification type — do not send `verification_type`.

```json
{
  "input_data": {
    "email": "customer@example.com",
    "language": "EN",
    "risk_assessment": {
      "phone_number": "+2348012345678",
      "risk_reference": "3miTFA"
    }
  }
}
```
