# Risk Assessment

Assess the fraud and identity risk score for a given individual based on their identity data.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/`
- Detail: `GET /api/v2/public/verifications/requests/{verification_id}/detail/`
:::

## Verification Type

```
risk_assessment
```

:::caution Not available on public create
This verification type currently requires a hosted (`onsite`) flow and is **not supported** by `POST /api/v2/public/verifications/requests/` (which always uses direct/offsite mode).
:::

## Use Cases

- Fraud scoring during account opening
- Transaction risk evaluation
- Identity-based risk tiering

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id_number` | string | Yes | The identity number to assess. |
| `id_type` | string | Yes | Type of ID (e.g., "national_id", "passport", "bvn"). |
| `country` | string | Yes | ISO 3166-1 alpha-2 country code. |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.


**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `risk_assessment`.

```json
{
  "verification_type": "risk_assessment",
  "input_data": { /* see parameters above */ }
}
```
