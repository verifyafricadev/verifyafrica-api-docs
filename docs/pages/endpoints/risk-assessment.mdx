# Risk Assessment

Assess the fraud and identity risk score for a given individual based on their identity data.

:::tip API Reference
Jump directly to the interactive API docs for this endpoint:

- [Single API reference](/api/single-risk-crypto#risk-assessment) — schemas, examples, and playground
- [Bulk API reference](/api/bulk-risk-crypto#risk-assessment) — schemas, examples, and playground for batch requests
:::

## Verification Type

```
risk_assessment
```

## Use Cases

- Fraud scoring during account opening
- Transaction risk evaluation
- Identity-based risk tiering

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id_number` | string | Yes | The identity number to assess. |
| `id_type` | string | Yes | Type of ID (e.g., "national_id", "passport", "bvn"). |
| `country` | string | Yes | ISO 3166-1 alpha-2 country code. |

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/verifications/requests/`

Include your API key in the `X-API-KEY` header and set `verification_type` to `risk_assessment`.

```json
{
  "is_test": false,
  "verification_type": "risk_assessment",
  "input_data": { /* see parameters above */ }
}
```

## Bulk Processing

Bulk requests are supported. Include this verification in the `verifications` array when calling `/api/verifications/bulk/` (up to 100 records per batch).
