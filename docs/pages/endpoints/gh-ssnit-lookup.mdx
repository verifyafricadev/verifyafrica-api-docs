# Ghana SSNIT Lookup

Lookup Ghana Social Security and National Insurance Trust (SSNIT) records.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api/single-gov-ghana#ghana-ssnit-lookup) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/government_registry_checks/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
gh_ssnit_lookup
```

## Use Cases

- Social security record verification
- Employment identity checks

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `ssnit_number` | string | Yes | SSNIT number. |
| `first_name` | string | No | First name for cross-validation. |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.


**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/government_registry_checks/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `gh_ssnit_lookup`.

```json
{
  "verification_type": "gh_ssnit_lookup",
  "input_data": { /* see parameters above */ }
}
```



## Example Error Responses

Errors use the v2 envelope `{ "success": false, "message": "…", "errors": ["…"] }`.

```json
{
  "success": false,
  "message": "Invalid API key.",
  "errors": ["Invalid API key."]
}
```

