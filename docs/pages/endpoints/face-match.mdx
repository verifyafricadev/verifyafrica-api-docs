# Facial Screening

Perform real-time liveness detection and face match verification against a reference document.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api/single-identity-verification#facial-screening) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/`
- Detail: `GET /api/v2/public/verifications/requests/{verification_id}/detail/`
:::

## Verification Type

```
face_match
```

## Use Cases

- Confirm the person presenting an ID is the document holder
- Detect presentation attacks with liveness checks
- Combine with document verification for stronger KYC

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `face` | object | Yes | Face image and verification options. See nested fields below. |
| `email` | string | No | Customer's email address. |
| `language` | string | No | Language code (e.g. `"EN"`, `"FR"`). Defaults to `"EN"`. |
| `country` | string | No | ISO 3166-1 alpha-2 country code (e.g. `"NG"`, `"ZA"`, `"GH"`, `"KE"`). |

### `face` object

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `proof` | string | Yes | Face image. Accepts a base64 data URI (`data:image/jpeg;base64,...`) or an HTTPS URL to a `jpeg`/`jpg`/`png` file. |
| `verification_mode` | string | Yes | Capture type. One of: `"any"`, `"image_only"`, `"video_only"`. |
| `allow_offline` | boolean | No | Defaults to `false`. |
| `check_duplicate_request` | boolean | No | `true` to flag duplicate faces, `false` to allow. Defaults to `false`. |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.

**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `face_match`.

```json
{
  "verification_type": "face_match",
  "input_data": {
    "email": "customer@example.com",
    "language": "EN",
    "face": {
      "proof": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQAAAQABAAD...",
      "verification_mode": "any",
      "allow_offline": false,
      "check_duplicate_request": false
    }
  }
}
```
