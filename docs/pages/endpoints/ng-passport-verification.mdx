# Nigeria Passport Verification

Verify Nigerian international passport numbers against NIS records.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api/single-gov-nigeria#nigeria-passport-verification) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/government_registry_checks/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
ng_passport_verification
```

## Use Cases

- Passport authenticity checks
- Travel and immigration KYC

## Input Parameters

Pass these fields inside `input_data` in your request body.

**Required** below applies to **direct** mode. This check does not support selfie matching, so **link mode is not available**.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `passport_id` | string | Yes | Passport number (e.g., A01234567). |
| `last_name` | string | Yes | Last name as on the passport. |

## Modes

This check does **not** support selfie matching, so **link mode is not available**. Use `mode: "direct"`. See [Government Registry Checks](./overview/government-registry).

If `mode` is omitted it defaults to `direct`. Sending `mode: "link"` returns **400**.

Do not send internal `method_type`.

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/government_registry_checks/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `ng_passport_verification`.



```json
{
  "verification_type": "ng_passport_verification",
  "mode": "direct",
  "input_data": {
    "passport_id": "A01234567",
    "last_name": "Olakunle"
  }
}
```

Listen for `kr.verification.completed` / `kr.verification.failed` (or poll GET detail) for the terminal result.
