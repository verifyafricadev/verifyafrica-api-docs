# AML Screening

Screen individuals against global sanctions, PEP, watchlist, and adverse media sources in either **link** or **direct** mode.

Shufti Individual AML is name-based. There is no customer document upload.

| Mode | What you send | What create returns | When verification finishes |
| --- | --- | --- | --- |
| `link` (default) | Email plus optional countries, DOB, and filters | `data.link.url` for the customer | After the customer submits their name (and any unlocked fields) |
| `direct` | Full name plus screening config | Accepted request (`PENDING`) | After provider processing completes |

If you send `countries` (or a single `country`) or `dob` in **link** mode, those values are locked. The customer cannot send them, and the backend rejects them if they try.

Place screening categories in a top-level `filters` object. The same filters are applied to `background_checks` before the request is sent to Shufti.

Use [Webhooks](/webhooks) or `GET …/requests/?verification_id=…` for the terminal result in both modes. Error payloads include `internal_error_provider` and `internal_error_message`.

:::tip API Reference

- [AML Screening](/api/single-compliance-screening#aml-screening) — schemas, examples, and playground

## Verification Type

```
aml_screening
```

## Request body

| Parameter | Type | Link | Direct | Description |
| --- | --- | --- | --- | --- |
| `mode` | string | Optional (default `link`) | Optional | `"link"` or `"direct"`. |
| `input_data` | object | Required | Required | Customer details and screening options. |
| `send_email` | boolean | Optional (default `false`) | — | `true` to email the hosted link to `input_data.email`. |

### `input_data`

| Parameter | Type | Link | Direct | Description |
| --- | --- | --- | --- | --- |
| `email` | string | Required | Required | Customer's email address. |
| `language` | string | Optional (default `"EN"`) | Optional | Language code. |
| `ttl` | integer | Optional (default `60`) | — | Link lifetime in minutes: `15`, `30`, `60`, `120`, `240`. |
| `country` | string | Optional | Optional | ISO 3166-1 alpha-2. Compatibility alias for a single code; prefer `background_checks.countries`. Locks countries in link mode. |
| `filters` | object | Optional | Optional | `{ "filters": [...], "match_score": 100, "rca_search": true, "alias_search": true }`. Defaults: RCA and alias search on. |
| `background_checks` | object | Optional | Required | Subject details. Direct mode requires `name.full_name`. |

### `background_checks`

| Parameter | Type | Link | Direct | Description |
| --- | --- | --- | --- | --- |
| `name.full_name` | string | — | Required | Subject's full name. Collected on the hosted page in link mode. |
| `dob` | string | Optional | Optional | `YYYY-MM-DD`. Locks DOB in link mode. |
| `countries` | array of string | Optional | Optional | ISO 3166-1 alpha-2 codes. Leave empty for a global screen. Any values lock countries in link mode. |
| `filters` | array of string | Optional | Optional | Screening categories. Prefer the top-level `filters` object. |
| `match_score` | integer | Optional | Optional | `0`–`100`. Defaults to `100`. |
| `biometric_search_image` | string | Optional | Optional | HTTPS URL of a JPEG or PNG (max 5MB) for biometric matching. Do not send base64; the API fetches the URL and encodes it for Shufti. |
| `context` | string | Optional | Optional | Extra context used when assessing matches. |

Allowed filter values: `sanction`, `warning`, `fitness-probity`, `pep`, `pep-class-1`, `pep-class-2`, `pep-class-3`, `pep-class-4`, `adverse-media`.

`rca_search` includes relatives and close associates. `alias_search` matches known aliases. Both default to `true`.

## Link mode example

```json
{
  "mode": "link",
  "send_email": false,
  "input_data": {
    "email": "customer@example.com",
    "language": "EN",
    "ttl": 60,
    "filters": {
      "filters": ["sanction", "pep", "adverse-media"],
      "match_score": 80,
      "rca_search": true,
      "alias_search": true
    },
    "background_checks": {
      "biometric_search_image": "https://files.example.com/subject-face.jpg"
    }
  }
}
```

## Direct mode example

```json
{
  "mode": "direct",
  "input_data": {
    "email": "customer@example.com",
    "language": "EN",
    "country": "NG",
    "filters": {
      "filters": ["sanction", "pep", "adverse-media"],
      "match_score": 100,
      "rca_search": false,
      "alias_search": true
    },
    "background_checks": {
      "name": { "full_name": "John Doe" },
      "dob": "1990-01-15",
      "countries": ["NG"],
      "biometric_search_image": "https://files.example.com/subject-face.jpg",
      "context": "Onboarding for a regulated account"
    }
  }
}
```
