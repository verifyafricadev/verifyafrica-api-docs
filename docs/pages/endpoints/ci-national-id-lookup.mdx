# Côte d'Ivoire National ID Lookup

Verify Ivorian National ID records against the government registry via Korapay Identity.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api/single-gov-cote-divoire#cote-d-ivoire-national-id-lookup) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/government_registry_checks/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
ci_national_id_lookup
```

## Use Cases

- National ID verification for Côte d'Ivoire
- Onboarding and KYC for Ivorian citizens

## Input Parameters

Pass these fields inside `input_data` in your request body.

**Required** below means required in **direct** mode. In **link** mode those fields are optional prefills (omit them so the customer enters them on the hosted page).

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `national_id` | string | Yes | Ivorian National ID. **7–12 alphanumeric characters**; normalized to uppercase before Korapay. |
| `first_name` | string | No | First name for cross-validation. |
| `last_name` | string | No | Last name for cross-validation. |
| `date_of_birth` | string | No | Date of birth (YYYY-MM-DD). |
| `selfie` | string (URL) | No | Direct mode only — HTTPS selfie image URL for facial matching. |

## Modes

Supports **link** and **direct** mode (same product endpoint for every registry check). See [Government Registry Checks](./overview/government-registry) for shared request fields, billing, selfies, and webhooks.

| Mode | Notes |
| --- | --- |
| `link` (default) | Hosted page. Prefill fields to lock them; leave optional validation blank for the customer. Returns `data.link.url`. |
| `direct` | Send the required identifier now. Runs asynchronously. |

Do not send internal `method_type`. Use top-level `mode` instead.

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/government_registry_checks/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `ci_national_id_lookup`.

### Link mode

```json
{
  "verification_type": "ci_national_id_lookup",
  "mode": "link",
  "send_email": true,
  "input_data": {
    "email": "customer@example.com",
    "ttl": 60
  }
}
```

### Direct mode

```json
{
  "verification_type": "ci_national_id_lookup",
  "mode": "direct",
  "input_data": {
    "national_id": "00112233440"
  }
}
```

Listen for `kr.verification.completed` / `kr.verification.failed` (or poll GET detail) for the terminal result.

## Sandbox testing

With Korapay **test** keys, use the [Korapay sandbox identity numbers](https://developers.korapay.com/docs/testing-your-integration):

| Scenario | National ID |
| --- | --- |
| Valid | `00112233440` |

IDs are normalized to uppercase. Values outside 7–12 alphanumeric characters are rejected at create with HTTP 400.

## Example Error Responses

Errors use the v2 envelope `{ "success": false, "message": "…", "errors": ["…"] }`.

```json
{
  "success": false,
  "message": "national_id: National ID must be 7 to 12 characters.",
  "errors": ["national_id: National ID must be 7 to 12 characters."]
}
```

```json
{
  "success": false,
  "message": "Invalid API key.",
  "errors": ["Invalid API key."]
}
```
