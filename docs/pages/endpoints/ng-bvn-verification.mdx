# Nigeria BVN Verification

Verify Nigerian Bank Verification Numbers against the NIBSS database.

:::tip API Reference
Jump directly to the interactive API docs for this endpoint:

- [Single API reference](/api/single-gov-nigeria#nigeria-bvn-verification) — schemas, examples, and playground
- [Bulk API reference](/api/bulk-gov-nigeria#nigeria-bvn-verification) — schemas, examples, and playground for batch requests
:::

## Verification Type

```
ng_bvn_verification
```

## Use Cases

- Bank-grade identity verification
- Financial services KYC

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `bvn` | string | Yes | 11-digit Bank Verification Number. |
| `first_name` | string | No | First name for cross-validation. |
| `last_name` | string | No | Last name for cross-validation. |
| `date_of_birth` | string | No | Date of birth (YYYY-MM-DD). |

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/verifications/requests/`

Include your API key in the `X-API-KEY` header and set `verification_type` to `ng_bvn_verification`.

```json
{
  "is_test": false,
  "verification_type": "ng_bvn_verification",
  "input_data": { /* see parameters above */ }
}
```

## Bulk Processing

Bulk requests are supported. Include this verification in the `verifications` array when calling `/api/verifications/bulk/` (up to 100 records per batch).
