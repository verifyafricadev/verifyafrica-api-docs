# Address Verification

Verify physical address records against government and utility databases across Africa.

:::tip API Reference
Jump directly to the interactive API docs for this endpoint:

- [Single API reference](/api/single-address-verification#address-verification) — schemas, examples, and playground
- [Bulk API reference](/api/bulk-address-verification#address-verification) — schemas, examples, and playground for batch requests
:::

## Verification Type

```
address_verification
```

## Use Cases

- Proof-of-address checks during KYC
- Delivery and logistics address validation
- Utility and government record matching

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `address` | string | Yes | Full street address. |
| `city` | string | Yes | City or town name. |
| `state` | string | No | State or province. |
| `country` | string | Yes | ISO 3166-1 alpha-2 country code. |

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/verifications/requests/`

Include your API key in the `X-API-KEY` header and set `verification_type` to `address_verification`.

```json
{
  "is_test": false,
  "verification_type": "address_verification",
  "input_data": { /* see parameters above */ }
}
```

## Bulk Processing

Bulk requests are supported. Include this verification in the `verifications` array when calling `/api/verifications/bulk/` (up to 100 records per batch).
