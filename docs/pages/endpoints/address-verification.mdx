# Address Verification

Verify physical address records against government and utility databases across Africa.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/address_verification/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
address_verification
```

## Use Cases

- Proof-of-address checks during KYC
- Delivery and logistics address validation
- Utility and government record matching

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `address` | string | Yes | Full street address. |
| `city` | string | Yes | City or town name. |
| `state` | string | No | State or province. |
| `country` | string | Yes | ISO 3166-1 alpha-2 country code. |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.


**Endpoint:** POST https://api.verifyafrica.io/api/v2/public/verifications/requests/address_verification/address_verification/`

Authenticate with `Authorization: Bearer <VA-…api-key>`. The product path selects the verification type — do not send `verification_type`.

```json
{
  "input_data": { /* see parameters above */ }
}
```



## Example Error Responses

Errors use the v2 envelope `{ "success": false, "message": "…", "errors": ["…"] }`.

```json
{
  "success": false,
  "message": "Invalid API key.",
  "errors": ["Invalid API key."]
}
```

```json
{
```
