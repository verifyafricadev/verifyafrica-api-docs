# Kenya National ID Lookup

Lookup Kenyan national ID records from the National Registration Bureau.

:::tip API Reference
Jump directly to the interactive API docs for this endpoint:

- [Single API reference](/api/single-gov-kenya#kenya-national-id-lookup) — schemas, examples, and playground
- [Bulk API reference](/api/bulk-gov-kenya#kenya-national-id-lookup) — schemas, examples, and playground for batch requests
:::

## Verification Type

```
ke_national_id_lookup
```

## Use Cases

- National ID verification
- NRB record matching

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id_number` | string | Yes | Kenya national ID number. |
| `first_name` | string | No | First name for cross-validation. |

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/verifications/requests/`

Include your API key in the `X-API-KEY` header and set `verification_type` to `ke_national_id_lookup`.

```json
{
  "is_test": false,
  "verification_type": "ke_national_id_lookup",
  "input_data": { /* see parameters above */ }
}
```

## Bulk Processing

Bulk requests are supported. Include this verification in the `verifications` array when calling `/api/verifications/bulk/` (up to 100 records per batch).
