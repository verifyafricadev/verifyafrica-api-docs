# Kenya National ID Lookup

Lookup Kenyan national ID records from the National Registration Bureau.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api/single-gov-kenya#kenya-national-id-lookup) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/government_registry_checks/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
ke_national_id_lookup
```

## Use Cases

- National ID verification
- NRB record matching

## Input Parameters

Pass these fields inside `input_data` in your request body.

**Required** below means required in **direct** mode. In **link** mode those fields are optional prefills (omit them so the customer enters them on the hosted page). Link mode also requires `input_data.require_selfie` to be `true`.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `national_id` | string | Yes | Kenya national ID number. |
| `first_name` | string | No | First name for cross-validation. |
| `last_name` | string | No | Last name for cross-validation. |
| `date_of_birth` | string | No | Date of birth (YYYY-MM-DD). |
| `selfie` | string (URL) | No | Direct mode only — HTTPS selfie image URL. |

## Modes

This check supports Korapay **facial matching**, so **link mode is available only when you request a selfie** (`input_data.require_selfie: true`). Direct mode is always available. See [Government Registry Checks](./overview/government-registry) for shared request fields, billing, and webhooks.

| Mode | Notes |
| --- | --- |
| `direct` | Default unless `require_selfie` is true. Send the required identifier now. Optional `selfie` HTTPS URL. |
| `link` | Only when `input_data.require_selfie` is `true`. Hosted page for selfie capture (and any fields you omit). Returns `data.link.url`. |

Sending `mode: "link"` without `require_selfie: true` returns **400**. Do not send internal `method_type`.

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/government_registry_checks/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `ke_national_id_lookup`.

### Link mode

```json
{
  "verification_type": "ke_national_id_lookup",
  "mode": "link",
  "send_email": true,
  "input_data": {
    "email": "customer@example.com",
    "ttl": 60,
    "require_selfie": true
  }
}
```

### Direct mode

```json
{
  "verification_type": "ke_national_id_lookup",
  "mode": "direct",
  "input_data": {
    "national_id": "25219766"
  }
}
```

Listen for `kr.verification.completed` / `kr.verification.failed` (or poll GET detail) for the terminal result.
