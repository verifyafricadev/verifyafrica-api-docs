# Kenya National ID Lookup

Lookup Kenyan national ID records from the National Registration Bureau.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/`
- Detail: `GET /api/v2/public/verifications/requests/{verification_id}/detail/`
:::

## Verification Type

```
ke_national_id_lookup
```

## Use Cases

- National ID verification
- NRB record matching

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id_number` | string | Yes | Kenya national ID number. |
| `first_name` | string | No | First name for cross-validation. |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.


**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `ke_national_id_lookup`.

```json
{
  "verification_type": "ke_national_id_lookup",
  "input_data": { /* see parameters above */ }
}
```
