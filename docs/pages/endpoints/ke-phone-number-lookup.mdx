# Kenya Phone Lookup

Lookup subscriber information associated with a Kenyan phone number.

:::tip API Reference
Jump directly to the interactive API docs for this endpoint:

- [Single API reference](/api/single-gov-kenya#kenya-phone-lookup) — schemas, examples, and playground
- [Bulk API reference](/api/bulk-gov-kenya#kenya-phone-lookup) — schemas, examples, and playground for batch requests
:::

## Verification Type

```
ke_phone_number_lookup
```

## Use Cases

- Phone subscriber lookup
- MSISDN identity matching

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `phone_number` | string | Yes | Kenyan phone number (e.g., 0712345678). |

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/verifications/requests/`

Include your API key in the `X-API-KEY` header and set `verification_type` to `ke_phone_number_lookup`.

```json
{
  "is_test": false,
  "verification_type": "ke_phone_number_lookup",
  "input_data": { /* see parameters above */ }
}
```

## Bulk Processing

Bulk requests are supported. Include this verification in the `verifications` array when calling `/api/verifications/bulk/` (up to 100 records per batch).
