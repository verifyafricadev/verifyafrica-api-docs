**Test vs production**

On **test**, identity values are sandbox-specific — you must use the sandbox IDs listed in these docs. Real government IDs fail on test.

On **production**, you can use any real government ID. Sandbox values do not work with live credentials.

Lookup subscriber information associated with a Kenyan phone number.

**API Reference**

Jump directly to the interactive API docs:

- [API reference](/api/single-gov-kenya#kenya-phone-lookup) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/government_registry_checks/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`

## Verification Type

```
ke_phone_number_lookup
```

## Use Cases

- Phone subscriber lookup
- MSISDN identity matching

## Input Parameters

Pass these fields inside `input_data` in your request body.

**Required** below applies to **direct** mode. This check does not support selfie matching, so **link mode is not available**.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `phone_number` | string | Yes | Kenyan phone number (e.g., 0712345678). |
| `type` | string | Yes | Identity type linked to the phone — `national_id` or `passport`. |

## Modes

This check does **not** support selfie matching, so **link mode is not available**. Use `mode: "direct"`. See [Government Registry Checks](./overview/government-registry).

If `mode` is omitted it defaults to `direct`. Sending `mode: "link"` returns **400**.

Do not send internal `method_type`.

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/government_registry_checks/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `ke_phone_number_lookup`.

```json
{
  "verification_type": "ke_phone_number_lookup",
  "mode": "direct",
  "input_data": {
    "phone_number": "0723818211",
    "type": "national_id"
  }
}
```

Listen for `kr.verification.completed` / `kr.verification.failed` (or poll GET detail) for the terminal result.

## Sandbox testing (required on test)

On **test**, use the sandbox phone number. Real numbers fail on test.

| Scenario | `input_data.phone_number` | `input_data.type` |
| --- | --- | --- |
| Valid | `0723818211` | `national_id` or `passport` |

Only a valid Kenyan phone sandbox value is published.
