# Kenya Passport Lookup

Lookup Kenyan international passport records from immigration registries.

:::tip API Reference
Jump directly to the interactive API docs for this endpoint:

- [Single API reference](/api/single-gov-kenya#kenya-passport-lookup) — schemas, examples, and playground
- [Bulk API reference](/api/bulk-gov-kenya#kenya-passport-lookup) — schemas, examples, and playground for batch requests
:::

## Verification Type

```
ke_passport_lookup
```

## Use Cases

- Passport record verification
- Immigration identity checks

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `passport_number` | string | Yes | Kenya passport number (e.g., A1234567). |
| `first_name` | string | No | First name for cross-validation. |

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/verifications/requests/`

Include your API key in the `X-API-KEY` header and set `verification_type` to `ke_passport_lookup`.

```json
{
  "is_test": false,
  "verification_type": "ke_passport_lookup",
  "input_data": { /* see parameters above */ }
}
```

## Bulk Processing

Bulk requests are supported. Include this verification in the `verifications` array when calling `/api/verifications/bulk/` (up to 100 records per batch).
