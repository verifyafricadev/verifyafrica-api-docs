# South Africa ID Verification

Verify South African ID numbers against the Department of Home Affairs registry.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api/single-gov-south-africa#south-africa-id-verification) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/government_registry_checks/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
za_said_verification
```

## Use Cases

- Validate SA ID numbers during onboarding
- Cross-check name against Home Affairs records

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `id_number` | string | Yes | 13-digit South African ID number. |
| `first_name` | string | No | Subject's first name for cross-validation. |
| `last_name` | string | No | Subject's last name for cross-validation. |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.


**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/government_registry_checks/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `za_said_verification`.

```json
{
  "verification_type": "za_said_verification",
  "input_data": { /* see parameters above */ }
}
```
