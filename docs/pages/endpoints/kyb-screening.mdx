# KYB - Know Your Business

Perform full Know Your Business checks including ownership structure, beneficial owners, and registry data.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/kyb/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
kyb_screening
```

## Use Cases

- Verify company registration and status
- Retrieve directors and ownership data
- Support merchant and corporate onboarding

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `rc_number` | string | Yes | Company registration number. |
| `company_name` | string | No | Legal name of the business (used for cross-validation). |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.


**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/kyb/`

Authenticate with `Authorization: Bearer <VA-…api-key>`. The product path selects the verification type — do not send `verification_type`.

```json
{
  "input_data": { /* see parameters above */ }
}
```



## Example Error Responses

Errors use the v2 envelope `{ "success": false, "message": "…", "errors": ["…"] }`.

```json
{
  "success": false,
  "message": "Invalid API key.",
  "errors": ["Invalid API key."]
}
```

```json
{
  "success": false,
  "message": "Missing required parameters for 'kyb_screening': …",
  "errors": ["Missing required parameters for 'kyb_screening': …"]
}
```

See the [Introduction](/) for the full set of status-code examples, or the interactive [API Reference](/api).
