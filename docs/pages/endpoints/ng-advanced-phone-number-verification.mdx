# Nigeria Phone Verification

Verify Nigerian phone numbers with advanced carrier and identity validation.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/`
- Detail: `GET /api/v2/public/verifications/requests/{verification_id}/detail/`
:::

## Verification Type

```
ng_advanced_phone_number_verification
```

## Use Cases

- Phone-to-identity matching
- SIM and carrier validation

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `phone_number` | string | Yes | Nigerian phone number (e.g., 08012345678). |
| `first_name` | string | No | First name for cross-validation. |
| `last_name` | string | No | Last name for cross-validation. |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.


**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `ng_advanced_phone_number_verification`.

```json
{
  "verification_type": "ng_advanced_phone_number_verification",
  "input_data": { /* see parameters above */ }
}
```



## Example Error Responses

Errors use the v2 envelope `{ "success": false, "message": "…", "errors": ["…"] }`.

```json
{
  "success": false,
  "message": "Invalid API key.",
  "errors": ["Invalid API key."]
}
```

```json
{
  "success": false,
  "message": "Missing required parameters for 'ng_advanced_phone_number_verification': …",
```
