# Nigeria CAC Lookup

Lookup company records from the Nigerian Corporate Affairs Commission (CAC).

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api/single-gov-nigeria#nigeria-cac-lookup) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/government_registry_checks/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
ng_cac_lookup
```

## Use Cases

- Business registration verification
- Corporate due diligence

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `rc_number` | string | Yes | CAC registration number (e.g., RC123456). |
| `company_name` | string | No | Company name for cross-validation. |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.


**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/government_registry_checks/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `ng_cac_lookup`.

```json
{
  "verification_type": "ng_cac_lookup",
  "input_data": { /* see parameters above */ }
}
```



## Example Error Responses
