# 🇺🇸 United States

Official government registry checks for the United States.

## API Reference

- [Country operations](/api/single-gov-united-states)

All checks in this country use the same product endpoint:

`POST /api/v2/public/verifications/requests/government_registry_checks/`

Set `verification_type` to the identifier for the check you need. Retrieve results with `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`.

Every check supports **link** and **direct** mode. See [Government Registry Checks](../government-registry) for shared `mode`, billing, and webhook details.

SSN verification requires the holder's first name, last name, date of birth, and US phone number alongside the SSN. Korapay processes it asynchronously.
