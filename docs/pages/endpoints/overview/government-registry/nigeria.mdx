:::tip Test vs production
On **test**, identity values are sandbox-specific — you must use the sandbox IDs listed in these docs. Real government IDs fail on test.

On **production**, you can use any real government ID. Sandbox values do not work with live credentials.
:::

Official government registry checks for Nigeria.

## API Reference

- [Country operations](/api/single-gov-nigeria)

All checks in this country use the same product endpoint:

`POST /api/v2/public/verifications/requests/government_registry_checks/`

Set `verification_type` to the identifier for the check you need. Retrieve results with `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`.

Every check supports **link** and **direct** mode. See [Government Registry Checks](../government-registry) for shared `mode`, selfie, billing, and webhook details.

## Sandbox testing (required on test)

On the **test** environment you must use sandbox IDs Real Nigerian IDs fail on test.

| Check | `verification_type` | Request key | Valid | Invalid |
| --- | --- | --- | --- | --- |
| [BVN](../../ng-bvn-verification) | `ng_bvn_verification` | `bvn` | `22222222222` | `00000000000` |
| [NIN](../../ng-nin-verification) | `ng_nin_verification` | `nin` | `55555555555` | `00000000000` |
| [Virtual NIN](../../ng-virtual-nin-verification) | `ng_virtual_nin_verification` | `virtual_nin` | `KO111111111111IL` | `KO000000000000II` |
| [Passport](../../ng-passport-verification) | `ng_passport_verification` | `passport_id` | `A01234567` | `A00000000` |
| [Phone lookup](../../ng-phone-number-lookup) | `ng_phone_number_lookup` | `phone_number` | `08000000000` | `08000000001` |
| [Advanced phone](../../ng-advanced-phone-number-verification) | `ng_advanced_phone_number_verification` | `phone_number` | `08000000000` | `08000000001` |
| [CAC](../../ng-cac-lookup) | `ng_cac_lookup` | `cac_number` | `RC00000011` | `RC11111111` |

See also and the shared tables under [Government Registry Checks → Sandbox testing](../government-registry#sandbox-testing-required-on-test).
