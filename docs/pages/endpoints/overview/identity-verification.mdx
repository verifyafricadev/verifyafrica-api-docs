# Identity Verification

Verify government-issued identity documents and perform biometric checks across 47+ African countries.

## API Reference

- [API Reference](/api)

## Available Endpoints

- [Document Verification](../id-document) — Verify government-issued identity documents such as passports, national IDs, and driver's licenses across 47+ African countries. ([API](/api))
- [Facial Screening](../face-match) — Perform real-time liveness detection and face match verification against a reference document. ([API](/api))

## Getting Started

Use the product create endpoints:

- `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/document_verification/`
- `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/facial_screening/`

Retrieve results with `GET https://api.verifyafrica.io/api/v2/public/verifications/requests/?verification_id={verification_id}`.

Authenticate with `Authorization: Bearer <VA-…api-key>`. The product path selects the verification type — do not send `verification_type`.

Both endpoints support **`mode=link`** (default; returns a hosted capture URL) and **`mode=direct`** (send HTTPS proof URLs). See each page for required fields per mode.
