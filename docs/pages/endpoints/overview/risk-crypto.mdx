# Risk & Crypto

Assess identity fraud risk and screen cryptocurrency wallets for illicit activity.

## API Reference

- [API Reference](/api)

## Available Endpoints

- [Risk Assessment](../risk-assessment) — Assess the fraud and identity risk score for a given individual based on their identity data. ([API](/api))
- [Crypto Wallet Screening](../crypto-wallet-screening) — Screen cryptocurrency wallet addresses for sanctions exposure, darknet activity, and illicit fund sources. ([API](/api))

## Getting Started

Create via product-scoped endpoints:

- `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/risk_assessment/`
- `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/crypto_wallet_screening/`

Retrieve a verification with `GET https://api.verifyafrica.io/api/v2/public/verifications/requests/?verification_id={verification_id}`.
