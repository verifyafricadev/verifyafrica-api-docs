# Address Verification

Verify physical addresses against government and utility databases across Africa.

## API Reference

- [Single API — Address Verification](/api/single-address-verification)
- [Bulk API — Address Verification](/api/bulk-address-verification)

## Available Endpoints

- [Address Verification](../address-verification) — Verify physical address records against government and utility databases across Africa. ([API](/api/single-address-verification#address-verification))

## Getting Started

All endpoints in this category use the same base URL:

`POST https://api.verifyafrica.io/api/verifications/requests/`

Set `verification_type` to the identifier for the check you need. See each endpoint page for required `input_data` fields.
