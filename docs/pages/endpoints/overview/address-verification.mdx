# Address Verification

Verify physical addresses against government and utility databases across Africa.

## API Reference

- [API Reference](/api)

## Available Endpoints

- [Address Verification](../address-verification) — Verify physical address records against government and utility databases across Africa. ([API](/api))

## Getting Started

Use the product create endpoint:

`POST https://api.verifyafrica.io/api/v2/public/verifications/requests/address_verification/`

Retrieve results with `GET https://api.verifyafrica.io/api/v2/public/verifications/requests/?verification_id={verification_id}`.

Authenticate with `Authorization: Bearer <VA-…api-key>`. The product path selects the verification type — do not send `verification_type`.

Supports **`mode=link`** (default; returns a hosted capture URL) and **`mode=direct`** (send HTTPS proof URLs). See the endpoint page for required fields per mode.
