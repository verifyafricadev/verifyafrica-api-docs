# Ghana Driver's License

Lookup Ghanaian driver's license records from the DVLA registry.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api/single-gov-ghana#ghana-drivers-license-lookup) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/government_registry_checks/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
gh_drivers_license_lookup
```

## Use Cases

- Driver's license validation
- DVLA record lookup

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `license_number` | string | Yes | Driver's license number. |
| `first_name` | string | No | First name for cross-validation. |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.


**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/government_registry_checks/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `gh_drivers_license_lookup`.

```json
{
  "verification_type": "gh_drivers_license_lookup",
  "input_data": { /* see parameters above */ }
}
```



## Example Error Responses
