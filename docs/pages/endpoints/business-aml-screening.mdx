# Business AML Screening

Screen companies, organisations, vessels, and aircraft against sanctions, warnings, fitness and probity, adverse media, SIE, and insolvency records.

Shufti Business AML is name-based. There is no customer document upload.

| Mode | What you send | What create returns | When verification finishes |
| --- | --- | --- | --- |
| `link` (default) | Email plus optional countries, business name, incorporation date, and filters | `data.link.url` | After the customer confirms or enters the business name |
| `direct` | Business name plus screening config | Accepted request (`PENDING`) | After provider processing completes |

If you send `countries` (or a single `country`) or `business_incorporation_date` in **link** mode, those values are locked. An optional `business_name` is shown to the customer and can still be edited.

Place screening categories in a top-level `filters` object.

Use [Webhooks](/webhooks) for `verification.completed` / `verification.failed`. Error payloads include `internal_error_provider` and `internal_error_message`.

:::tip API Reference
- [Business AML Screening](/api/single-compliance-screening#business-aml-screening) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/business_aml_screening/`
:::

## Verification Type

```
business_aml_screening
```

## Request body

| Parameter | Type | Link | Direct | Description |
| --- | --- | --- | --- | --- |
| `mode` | string | Optional (default `link`) | Optional | `"link"` or `"direct"`. |
| `input_data` | object | Required | Required | Business details and screening options. |
| `send_email` | boolean | Optional | — | Email the hosted link. |

### `input_data`

| Parameter | Type | Link | Direct | Description |
| --- | --- | --- | --- | --- |
| `email` | string | Required | Required | Customer's email. |
| `ttl` | integer | Optional (default `60`) | — | Link lifetime in minutes. |
| `country` | string | Optional | Optional | ISO 3166-1 alpha-2. Compatibility alias for a single code; prefer `aml_for_businesses.countries`. Locks countries in link mode. |
| `filters` | object | Optional | Optional | `{ "filters": [...], "match_score": 100, "rca_search": true, "alias_search": true }`. |
| `aml_for_businesses` | object | Optional | Required | Direct mode requires `business_name`. |

### `aml_for_businesses`

| Parameter | Type | Link | Direct | Description |
| --- | --- | --- | --- | --- |
| `business_name` | string | Optional | Required | Shown to the customer in link mode; they can still change it. |
| `business_incorporation_date` | string | Optional | Optional | `YYYY-MM-DD`. Locks the date in link mode. |
| `countries` | array of string | Optional | Optional | ISO 3166-1 alpha-2 codes. Leave empty for a global screen. Any values lock countries in link mode. |
| `biometric_search_image` | string | Optional | Optional | HTTPS URL of a JPEG or PNG (max 5MB) for biometric matching. Do not send base64. |
| `individual_face` | string | Optional | Optional | HTTPS URL of a JPEG, PNG, or PDF (max 16MB). Do not send base64. |
| `context` | string | Optional | Optional | Extra context used when assessing matches. |

Allowed filter values match [AML Screening](/endpoints/aml-screening).

`rca_search` includes relatives and close associates. `alias_search` matches known aliases. Both default to `true`.

## Link mode example

```json
{
  "mode": "link",
  "input_data": {
    "email": "customer@example.com",
    "language": "EN",
    "ttl": 60,
    "filters": {
      "filters": ["sanction", "warning"],
      "match_score": 100
    },
    "aml_for_businesses": {
      "business_name": "Acme Corp Ltd"
    }
  }
}
```

## Direct mode example

```json
{
  "mode": "direct",
  "input_data": {
    "email": "customer@example.com",
    "language": "EN",
    "filters": {
      "filters": ["sanction", "warning"],
      "match_score": 100,
      "rca_search": true,
      "alias_search": true
    },
    "aml_for_businesses": {
      "business_name": "Acme Corp Ltd",
      "business_incorporation_date": "2010-06-15",
      "countries": ["NG", "GH"],
      "biometric_search_image": "https://files.example.com/subject-face.jpg",
      "individual_face": "https://files.example.com/ubo-face.pdf",
      "context": "Onboarding for a regulated account"
    }
  }
}
```
