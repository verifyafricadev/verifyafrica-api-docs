# Nigeria Virtual NIN

Verify Nigerian Virtual National Identification Numbers issued by NIMC.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api/single-gov-nigeria#nigeria-virtual-nin) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/government_registry_checks/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
ng_virtual_nin_verification
```

## Use Cases

- Privacy-preserving NIN verification
- vNIN token validation

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `vnin` | string | Yes | 16-character Virtual NIN. |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.


**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/government_registry_checks/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `ng_virtual_nin_verification`.

```json
{
  "verification_type": "ng_virtual_nin_verification",
  "input_data": { /* see parameters above */ }
}
```
