# Nigeria Virtual NIN

Verify Nigerian Virtual National Identification Numbers issued by NIMC.

:::tip API Reference
Jump directly to the interactive API docs for this endpoint:

- [Single API reference](/api/single-gov-nigeria#nigeria-virtual-nin) — schemas, examples, and playground
- [Bulk API reference](/api/bulk-gov-nigeria#nigeria-virtual-nin) — schemas, examples, and playground for batch requests
:::

## Verification Type

```
ng_virtual_nin_verification
```

## Use Cases

- Privacy-preserving NIN verification
- vNIN token validation

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `vnin` | string | Yes | 16-character Virtual NIN. |

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/verifications/requests/`

Include your API key in the `X-API-KEY` header and set `verification_type` to `ng_virtual_nin_verification`.

```json
{
  "is_test": false,
  "verification_type": "ng_virtual_nin_verification",
  "input_data": { /* see parameters above */ }
}
```

## Bulk Processing

Bulk requests are supported. Include this verification in the `verifications` array when calling `/api/verifications/bulk/` (up to 100 records per batch).
