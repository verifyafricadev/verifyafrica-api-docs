# Nigeria NIN Verification

Verify Nigerian National Identification Numbers against the NIMC database.

:::tip API Reference
Jump directly to the interactive API docs for this endpoint:

- [Single API reference](/api/single-gov-nigeria#nigeria-nin-verification) — schemas, examples, and playground
- [Bulk API reference](/api/bulk-gov-nigeria#nigeria-nin-verification) — schemas, examples, and playground for batch requests
:::

## Verification Type

```
ng_nin_verification
```

## Use Cases

- National ID verification
- Government identity matching

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `nin` | string | Yes | 11-digit National Identification Number. |
| `first_name` | string | No | First name for cross-validation. |
| `last_name` | string | No | Last name for cross-validation. |

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/verifications/requests/`

Include your API key in the `X-API-KEY` header and set `verification_type` to `ng_nin_verification`.

```json
{
  "is_test": false,
  "verification_type": "ng_nin_verification",
  "input_data": { /* see parameters above */ }
}
```

## Bulk Processing

Bulk requests are supported. Include this verification in the `verifications` array when calling `/api/verifications/bulk/` (up to 100 records per batch).
