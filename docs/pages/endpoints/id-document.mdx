# Document Verification

Verify government-issued identity documents such as passports, national IDs, and driver's licenses across 47+ African countries.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/document_verification/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
id_document
```

## Use Cases

- Onboard customers with government-issued ID validation
- Support passports, national IDs, and driver's licenses
- Validate government-issued IDs with direct document proofs

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `email` | string | Yes | Customer's email address. |
| `language` | string | Yes | Language code (e.g. `"EN"`, `"FR"`). |
| `document` | object | Yes | Document proof and matching options. See nested fields below. |
| `country` | string | No | ISO 3166-1 alpha-2 country code (e.g. `"NG"`, `"ZA"`, `"GH"`, `"KE"`). |
| `first_name` | string | No | Customer's first name for cross-validation. |
| `last_name` | string | No | Customer's last name for cross-validation. |

### `document` object

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `proof` | string | Yes | HTTPS URL to the front of the identity document (`jpeg`/`jpg`/`png`/`pdf`). Base64 data URIs are **not** accepted on the public API. |
| `backside_proof` | string | No | HTTPS URL to the back of the document, same formats as `proof`. |
| `backside_proof_required` | boolean | No | `true` to require a back image, `false` to skip it. Defaults to `false`. |
| `verification_mode` | string | No | Capture mode hint. Common value: `"any"`. |
| `fetch_enhanced_data` | boolean | No | `true` to return enhanced OCR/extracted fields, `false` to skip. Defaults to `true`. |
| `name` | object | No | Optional name matching details for the document owner. |

### `document.name` object

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `first_name` | string | No | Expected first name on the document. |
| `last_name` | string | No | Expected last name on the document. |
| `fuzzy_match` | boolean | No | `true` to allow fuzzy name matching, `false` for exact match. Defaults to `true`. |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.

The create response returns immediately with `status: PENDING`. Use [Webhooks](/webhooks) or the GET detail endpoint for the final result. GET and webhook payloads echo your original `document.proof` URL in both `input_data` and top-level `proofs`.

**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/document_verification/`

Authenticate with `Authorization: Bearer <VA-…api-key>`. The product path selects the verification type — do not send `verification_type`.

```json
{
  "input_data": {
    "email": "customer@example.com",
    "language": "EN",
    "country": "NG",
    "first_name": "John",
    "last_name": "Doe",
    "document": {
      "proof": "https://cdn.example.com/documents/id-front.jpg",
      "backside_proof_required": false,
      "verification_mode": "any",
      "fetch_enhanced_data": true,
      "name": {
        "first_name": "John",
        "last_name": "Doe",
        "fuzzy_match": true
      }
    }
  }
}
```


## Example Error Responses

Errors use the v2 envelope `{ "success": false, "message": "…", "errors": ["…"] }`.

```json
{
  "success": false,
  "message": "Invalid API key.",
  "errors": ["Invalid API key."]
}
```

```json
{
  "success": false,
  "message": "Missing required parameters for 'id_document': …",
  "errors": ["Missing required parameters for 'id_document': …"]
}
```

```json
{
  "success": false,
  "message": "…",
  "errors": [
    "input_data.document.proof: Must be an http(s) URL to the proof file. Base64 data URIs are not accepted."
  ]
}
```
