# Kenya Tax PIN Verification

Verify Kenyan KRA Personal Identification Numbers.

:::tip API Reference
Jump directly to the interactive API docs for this endpoint:

- [Single API reference](/api/single-gov-kenya#kenya-tax-pin-verification) — schemas, examples, and playground
- [Bulk API reference](/api/bulk-gov-kenya#kenya-tax-pin-verification) — schemas, examples, and playground for batch requests
:::

## Verification Type

```
ke_tax_pin_verification
```

## Use Cases

- KRA PIN validation
- Taxpayer identity verification

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `tax_pin` | string | Yes | Kenya Revenue Authority PIN (e.g., A123456789B). |
| `name` | string | No | Taxpayer name for cross-validation. |

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/verifications/requests/`

Include your API key in the `X-API-KEY` header and set `verification_type` to `ke_tax_pin_verification`.

```json
{
  "is_test": false,
  "verification_type": "ke_tax_pin_verification",
  "input_data": { /* see parameters above */ }
}
```

## Bulk Processing

Bulk requests are supported. Include this verification in the `verifications` array when calling `/api/verifications/bulk/` (up to 100 records per batch).
