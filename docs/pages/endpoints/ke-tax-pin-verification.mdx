# Kenya Tax PIN Verification

Verify Kenyan KRA Personal Identification Numbers.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api/single-gov-kenya#kenya-tax-pin-verification) — schemas, examples, and playground
- Create: `POST /api/v2/public/verifications/requests/government_registry_checks/`
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
ke_tax_pin_verification
```

## Use Cases

- KRA PIN validation
- Taxpayer identity verification

## Input Parameters

Pass these fields inside `input_data` in your request body.

**Required** below means required in **direct** mode. In **link** mode those fields are optional prefills (omit them so the customer enters them on the hosted page).

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `tax_pin` | string | Yes | Kenya Revenue Authority PIN (e.g., A123456789B). |

## Modes

Supports **link** and **direct** mode (same product endpoint for every registry check). See [Government Registry Checks](./overview/government-registry) for shared request fields, billing, selfies, and webhooks.

| Mode | Notes |
| --- | --- |
| `link` (default) | Hosted page. Prefill fields to lock them; leave optional validation blank for the customer. Returns `data.link.url`. |
| `direct` | Send the required identifier now. Runs asynchronously. |

Do not send internal `method_type`. Use top-level `mode` instead.

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/v2/public/verifications/requests/government_registry_checks/`

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `ke_tax_pin_verification`.

### Link mode

```json
{
  "verification_type": "ke_tax_pin_verification",
  "mode": "link",
  "send_email": true,
  "input_data": {
    "email": "customer@example.com",
    "ttl": 60
  }
}
```

### Direct mode

```json
{
  "verification_type": "ke_tax_pin_verification",
  "mode": "direct",
  "input_data": {
    "tax_pin": "A009274635J"
  }
}
```

Listen for `kr.verification.completed` / `kr.verification.failed` (or poll GET detail) for the terminal result.
