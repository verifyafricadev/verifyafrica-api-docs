# Ghana Voter Card Lookup

Lookup Ghanaian voter identification card records.

:::tip API Reference
Jump directly to the interactive API docs for this endpoint:

- [Single API reference](/api/single-gov-ghana#ghana-voter-card-lookup) — schemas, examples, and playground
- [Bulk API reference](/api/bulk-gov-ghana#ghana-voter-card-lookup) — schemas, examples, and playground for batch requests
:::

## Verification Type

```
gh_voter_card_lookup
```

## Use Cases

- Voter ID verification
- Electoral roll matching

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `voter_id` | string | Yes | Ghana voter ID number. |
| `first_name` | string | No | First name for cross-validation. |

## Making a Request

**Endpoint:** `POST https://api.verifyafrica.io/api/verifications/requests/`

Include your API key in the `X-API-KEY` header and set `verification_type` to `gh_voter_card_lookup`.

```json
{
  "is_test": false,
  "verification_type": "gh_voter_card_lookup",
  "input_data": { /* see parameters above */ }
}
```

## Bulk Processing

Bulk requests are supported. Include this verification in the `verifications` array when calling `/api/verifications/bulk/` (up to 100 records per batch).
