# Crypto Wallet Screening

Screen cryptocurrency wallet addresses for sanctions exposure, darknet activity, and illicit fund sources.

:::tip API Reference
Jump directly to the interactive API docs:

- [API reference](/api) — schemas, examples, and playground
- Create: not available on the public API (onsite-only)
- Detail: `GET /api/v2/public/verifications/requests/?verification_id={verification_id}`
:::

## Verification Type

```
crypto_wallet_screening
```

:::caution Not available on public create
This verification type currently requires a hosted (`onsite`) flow and is **not supported** by the public product create endpoints.
:::

## Use Cases

- Crypto exchange compliance
- Wallet sanctions screening
- AML checks for digital asset flows

## Input Parameters

Pass these fields inside `input_data` in your request body.

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `wallet_address` | string | Yes | The cryptocurrency wallet address to screen. |
| `blockchain` | string | Yes | Blockchain network (e.g., "bitcoin", "ethereum", "tron"). |

## Making a Request

Public API creates always use **direct (offsite)** mode. Do not send `method_type` — the API forces `offsite`.


**Endpoint:** not available on the public API

Authenticate with `Authorization: Bearer <VA-…api-key>` and set `verification_type` to `crypto_wallet_screening`.

```json
{
  "verification_type": "crypto_wallet_screening",
  "input_data": { /* see parameters above */ }
}
```



## Example Error Responses
